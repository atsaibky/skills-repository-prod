# Writing

Whenever you produce writing content for me (posts, emails, docs, announcements, marketing copy, README prose, summaries, anything a human reads as writing rather than as code), check the draft against `~/.claude/forbidden.md` before you deliver it. Those patterns are the dead giveaways of AI writing. Rewrite any sentence that matches one.

The same list ships as the `writing-for-humans` skill, so it is available on machines where this file has not been bootstrapped.
